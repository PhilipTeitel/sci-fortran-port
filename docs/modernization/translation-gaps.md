# Translation Gap Analysis

**Source stack:** Fortran 90/95-style modules with Fortran 2003-era command intrinsics; authoritative repository `master` is `e586903`, while exact dialect, accepted production compiler/version, and numeric-library versions remain unresolved
**Target stack:** C# / .NET 8 / ASP.NET Core
**Date:** `2026-08-10`
